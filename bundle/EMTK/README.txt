EMTK framework with the script-runtime startup patch

EMTK (github.com/ExanimaModding/Toolkit) built from upstream b422845 with emtk-startup.patch: it starts native plugins and hands Lua script mods to the Exanima Lua Runtime.

Install: close Exanima, back up emtk_framework.dll beside your EMTK launcher, and put this one there. To undo, restore the backup. See EMTK-STARTUP.md.
